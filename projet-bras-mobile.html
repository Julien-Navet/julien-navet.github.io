de déchets

Réalisé en binôme, ce projet vise à concevoir un robot capable de se déplacer dans son environnement et de ramasser des déchets grâce à un bras robotisé monté sur une base mobile.

01 / Le projet

Un robot mobile pour collecter des déchets

Ce projet de fin d’études, mené en binôme, porte sur la conception d’un robot capable d’aller récupérer des déchets dans son environnement. Pour réunir déplacement et préhension dans un même système, nous avons associé une base mobile à un bras robotisé.

02 / L’architecture

Une base pour se déplacer, un bras pour saisir

Le TurtleBot3 Waffle constitue la base mobile du robot et assure sa navigation dans l’environnement. Le bras LeRobot SO-101 est fixé sur cette base ; il est destiné à atteindre et ramasser les déchets.

Cette architecture mobile-manipulatrice combine deux fonctions complémentaires : la base amène le robot à proximité d’un objet, puis le bras permet d’interagir avec celui-ci. L’intégration des deux sous-systèmes doit permettre de concevoir un robot cohérent, capable de se déplacer et d’effectuer une tâche de collecte.

03 / La conception

Intégrer le bras sur la plateforme mobile

L’un des enjeux est d’intégrer le bras sans gêner le déplacement de la base, tout en conservant une portée suffisante pour atteindre les déchets. Le modèle CAO présenté plus haut illustre l’implantation des deux sous-systèmes sur une seule plateforme.
